# 🎨 UI Kit и Дизайн-система (`:core:uikit`)

Модуль `:core:uikit` представляет собой независимую дизайн-систему приложения «Трекер личных финансов». 

---

## 🏛️ Архитектурные принципы

1. **Изоляция от бизнес-логики:** компоненты UI Kit ничего не знают о базах данных, репозиториях, Room или ViewModel. Они работают исключительно с примитивными типами (`Double`, `String`, `Boolean`) и чистыми моделями предметной области (`Account`, `Category`, `TransactionType`).
2. **Переиспользуемость и предсказуемость:** каждый компонент снабжён `@Preview` для светлой и тёмной тем и поддерживает дизайн-токены Material 3.
3. **Производительность (Zero-Jank):**
   - Форматирование чисел вынесено в кэшируемые утилиты (`AmountFormatter`), исключая нагрузку на Garbage Collector при рекомпозициях.
   - Анимации используют Layout-фазу (`Modifier.offset { IntOffset(...) }`), не вызывая лишних рекомпозиций всего дерева.
   - Скрытие софтверной клавиатуры и управление фокусом синхронизированы с фазами анимаций шторок.

## 📦 Каталог компонентов (`components/`)

### 1. `account/` — Карточки счетов
- **`AccountCardItem.kt`**
  - Интерактивная карточка счёта (160×100 dp, скругление 16 dp).
  - Отображает иконку счёта в цветной подложке, название и отформатированный баланс (например, `"43 965,72 ₽"` или `"-500 ₽"`).
  - Поддерживает состояние выбора `isSelected` (акцентная обводка 2 dp, насыщенный фон).
  - *Параметры:* `title`, `balance`, `accountIcon`, `isSelected`, `containerColor`, `contentColor`, `onClick`.
- **`AddAccountCardItem.kt`**
  - Карточка-кнопка добавления нового счёта в карусели.
  - Отображает круглый бэйдж с плюсом и заголовок действия (`"Добавить счёт"`, `"+ Счёт"`).
  - Имеет настраиваемую обводку (`border`) и полупрозрачный фон для гармоничного отображения как на мятном фоне главного экрана, так и внутри белых шторок.
  - *Параметры:* `title`, `accountIcon`, `containerColor`, `border`, `onClick`.

---

### 2. `button/` — Фирменные кнопки приложения
- **`AppButtons.kt` (`AppPrimaryButton`, `AppSecondaryButton`)**
  - Базовые кнопки формы со стандартизированной высотой (48 dp) и скруглением (14 dp).
  - `AppPrimaryButton` — акцентная заливка (`Primary`), белый контрастный текст, жирное начертание.
  - `AppSecondaryButton` — нейтральная приглушённая подложка (`surfaceVariant`), вторичный текст для отмены или возврата назад.

---

### 3. `category/` — Иконки и чипы категорий
- **`CategoryIcon.kt`**
  - Круглая подложка с центрированной иконкой категории нужного размера и цвета.
  - Содержит системную функцию-резолвер `getCategoryIcon(iconRes: String?): ImageVector`, безопасно маппящую строковые ключи из базы данных (`"shopping_cart"`, `"restaurant"`, `"directions_bus"`, `"work"`, `"swap_horiz"`, `"home"`, `"theater_comedy"`, `"favorite"`, `"more_horiz"`) в векторные иконки Material Icons.
- **`CategoryIconChip.kt`**
  - Вертикальный интерактивный элемент выбора категории (круглая иконка 44 dp + подпись под ней).
  - При выборе (`isSelected = true`) подсвечивается внешним акцентным кольцом и насыщенным фоном.

---

### 4. `input/` — Поля ввода и форматирование на лету
- **`AmountInputField.kt`**
  - Специализированное поле ввода денежной суммы:
    - Числовая клавиатура с десятичной точкой (`KeyboardType.Decimal`).
    - Фильтрация ввода: запрет лишних символов, ограничение до двух знаков после запятой.
    - Визуальное разделение тысяч пробелами на лету.
    - Суффикс валюты `"₽"`.
    - Поддержка валидации ошибок (`isError`, `errorMessage`) и действия `ImeAction.Done`.
- **`ThousandsSeparatorVisualTransformation.kt`**
  - Кастомная реализация `VisualTransformation` с двусторонним `OffsetMapping`. Разделяет тысячи пробелами (`1250000.50` $\rightarrow$ `1 250 000.50`), не модифицируя исходное состояние строки.
- **`DateTimePickerRow.kt`**
  - Компактная плашка выбора даты операции с отображением относительных дней («Сегодня», «Вчера», «12 мая»).

---

### 5. `sheet/` — Базовые шторки ввода
- **`AppFormBottomSheet.kt`**
  - Фундаментальный шаблон нижней шторки (Material 3 `ModalBottomSheet`):
    - **Безопасный автофокус:** запрос фокуса через `onSheetOpened` строго после завершения анимации открытия шторки (без рывков и просадок FPS).
    - **Плавное закрытие:** вызов закрытия анимированно опускает шторку до конца перед удалением из композиции.
    - **Умное скрытие клавиатуры:** свайп шторки вниз мгновенно убирает экранную клавиатуру.
    - **Адаптивный подъём:** поддержка `imeNestedScroll` для плавного подъёма полей ввода над клавиатурой.
    - **Горизонтальный футер:** асимметричные кнопки «Назад» (1f) и «Добавить» (1.3f).

---

### 6. `text/` и `util/` — Типографика и форматирование сумм
- **`AmountFormatter.kt` (`util/`)**
  - Синглтон для высокопроизводительного форматирования валюты.
  - Кэширует символы российской локали (пробел между тысячами, запятая для копеек).
  - Скрывает нулевые копейки (`1 500,00 ₽` $\rightarrow$ `1 500 ₽`).
  - Сохраняет знак минус для отрицательных балансов счетов.
- **`AmountText.kt`**
  - Семантический компонент суммы:
    - `INCOME` $\rightarrow$ зелёный цвет (`IncomeGreen`), префикс `"+ "`.
    - `EXPENSE` $\rightarrow$ цвет текста по умолчанию, префикс `"− "`.
    - `TRANSFER` $\rightarrow$ синий цвет (`TransferBlue`), без знака.
    - Отрицательный баланс счёта $\rightarrow$ префикс `"− "`.
- **`DateHeader.kt`**
  - Заголовок дня в ленте транзакций с отображением чистого сальдо дня (доходы минус расходы) через `AmountText`.

---

### 7. `transaction/` — Элементы ленты операций
- **`TransactionTypeSelector.kt`**
  - Сегментированный переключатель типа операции («Расход», «Доход», «Перевод»).
  - Плавная пружинная анимация скользящей плашки (`animateDpAsState` + `Modifier.offset { IntOffset(...) }`).
- **`TransactionRowItem.kt`**
  - Строка операции в ленте истории: иконка категории, название, подзаголовок (счёт списания $\rightarrow$ счёт зачисления и заметка), отформатированная сумма.
