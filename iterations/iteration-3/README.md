# 📦 Итерация 3: Переход на многомодульность, слой данных (Room DB) и навигация

## 🎯 Цели итерации

1. **Архитектурный фундамент:** переход на многомодульную структуру (`:app`, `:core:model`, `:core:uikit`, `:core:database`, `:feature:home`).
2. **Локальное хранилище данных:** проектирование таблиц Room (`Entity`), интерфейсов `DAO`, конвертеров и автоматического предзаполнения стартовыми данными (дефолтный счёт «Наличные», базовые категории трат и доходов).
3. **Реактивный слой данных:** реализация репозиториев с возвратом `Flow` и внедрением через Koin.
4. **Интерактивный MVP-интерфейс (Демо-версия):** перенос ключевых компонентов из UI-макета в Compose, сборка главного экрана с живым отображением баланса, счетов и списка операций, а также рабочей нижней навигацией (`BottomBar` с центральной кнопкой `+`).

## 📋 Детализированный чеклист задач

### 1. Архитектура и модули
- [x] Декомпозиция монолита на базовые модули:
    - [x] `:core:model` — чистые Kotlin-модели (`Account`, `Category`, `Transaction`, энумы);
    - [x] `:core:uikit` — тема Material 3 (`Theme.kt`, `Color.kt`, `Type.kt`);
    - [x] `:feature:home` — стартовый модуль экрана дашборда;
    - [x] `:app` — запускающий модуль и хост навигации.
- [x] Настройка Compose Compiler для Kotlin 2.4 во всех UI-библиотеках.

### 2. Слой локальной базы данных (`:core:database`)
- [x] Создание Android-модуля `:core:database` и подключение Room + KSP.
- [x] Описание таблиц Room (`Entity`):
    - [x] `AccountEntity` — ID, название, баланс, валюта, цвет/иконка;
    - [x] `CategoryEntity` — ID, название, тип (доход/расход), месячный лимит, иконка;
    - [x] `TransactionEntity` — ID, сумма, тип, дата (`Instant`), связь с `accountId` и `categoryId`.
- [x] Написание `TypeConverters` для дат и enum-значений.
- [x] Реализация реактивных интерфейсов `DAO` на Kotlin Coroutines & `Flow`:
    - [x] `AccountDao` — чтение счетов, обновление балансов при транзакциях;
    - [x] `CategoryDao` — получение категорий по типам;
    - [x] `TransactionDao` — получение последних транзакций, добавление и удаление.
- [x] Конфигурация `AppDatabase` с колбэком предзаполнения стартовыми данными при создании БД (`RoomDatabase.Callback`).

### 3. Репозитории и Koin DI
- [x] Реализация мапперов `Entity` $\leftrightarrow$ `Domain Model`.
- [x] Реализация контрактов репозиториев (`AccountRepositoryImpl`, `TransactionRepositoryImpl`, `CategoryRepositoryImpl`).
- [x] Настройка Koin-модулей:
    - [x] `databaseModule` — предоставление экземпляров `AppDatabase` и DAO;
    - [x] `repositoryModule` — привязка реализаций к domain-интерфейсам;
    - [x] `homeViewModelModule` — внедрение UseCase/репозиториев во ViewModel дашборда;
    - [x] Инициализация общего списка модулей в `App.kt` (`FinanceTrackerApp.kt`).
