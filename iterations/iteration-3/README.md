# 📦 Итерация 3: Переход на многомодульность, слой данных (Room DB) и навигация

## 🎯 Цели итерации

1. **Архитектурный фундамент:** переход на многомодульную структуру (`:app`, `:core:model`, `:core:uikit`, `:core:database`, `:feature:home`).
2. **Локальное хранилище данных:** проектирование таблиц Room (`Entity`), интерфейсов `DAO`, конвертеров и автоматического предзаполнения стартовыми данными (дефолтный счёт «Наличные», базовые категории трат и доходов).
3. **Реактивный слой данных:** реализация репозиториев с возвратом `Flow` и внедрением через Koin.
4. **Интерактивный MVP-интерфейс (Демо-версия):** перенос ключевых компонентов из UI-макета в Compose, сборка главного экрана с живым отображением баланса, счетов и списка операций, а также рабочей нижней навигацией (`BottomBar` с центральной кнопкой `+`).

## 📋 Детализированный чеклист задач

### 1. Архитектура и модули
- [x] Декомпозиция монолита на базовые модули:
    - [x] `:core:model` — чистые Kotlin-модели (`Account`, `Category`, `Transaction`, энумы);
    - [x] `:core:uikit` — тема Material 3 (`Theme.kt`, `Color.kt`, `Type.kt`);
    - [x] `:feature:home` — стартовый модуль экрана дашборда;
    - [x] `:app` — запускающий модуль и хост навигации.
- [x] Настройка Compose Compiler для Kotlin 2.4 во всех UI-библиотеках.

### 2. Слой локальной базы данных (`:core:database`)
- [ ] Создание Android-модуля `:core:database` и подключение Room + KSP.
- [ ] Описание таблиц Room (`Entity`):
    - [ ] `AccountEntity` — ID, название, баланс, валюта, цвет/иконка;
    - [ ] `CategoryEntity` — ID, название, тип (доход/расход), месячный лимит, иконка;
    - [ ] `TransactionEntity` — ID, сумма, тип, дата (`Instant`), связь с `accountId` и `categoryId`.
- [ ] Написание `TypeConverters` для дат и enum-значений.
- [ ] Реализация реактивных интерфейсов `DAO` на Kotlin Coroutines & `Flow`:
    - [ ] `AccountDao` — чтение счетов, обновление балансов при транзакциях;
    - [ ] `CategoryDao` — получение категорий по типам;
    - [ ] `TransactionDao` — получение последних транзакций, добавление и удаление.
- [ ] Конфигурация `AppDatabase` с колбэком предзаполнения стартовыми данными при создании БД (`RoomDatabase.Callback`).

### 3. Репозитории и Koin DI
- [ ] Реализация мапперов `Entity` $\leftrightarrow$ `Domain Model`.
- [ ] Реализация контрактов репозиториев (`AccountRepositoryImpl`, `TransactionRepositoryImpl`, `CategoryRepositoryImpl`).
- [ ] Настройка Koin-модулей:
    - [ ] `databaseModule` — предоставление экземпляров `AppDatabase` и DAO;
    - [ ] `repositoryModule` — привязка реализаций к domain-интерфейсам;
    - [ ] `homeViewModelModule` — внедрение UseCase/репозиториев во ViewModel дашборда;
    - [ ] Инициализация общего списка модулей в `App.kt`.

### 4. Навигационный каркас приложения (`:app` / `:core:uikit`)
- [ ] Реализация компонента нижней панели `BottomNavBar`:
    - [ ] Кнопки переключения основных разделов: **Главная**, **Аналитика**, **Профиль**;
    - [ ] Центральная акцентная кнопка действия (**FAB «+»**) для добавления новой операции.
- [ ] Базовый хост переходов на **Navigation 3**: обработка переключения вкладок и открытия модального окна добавления транзакции.

### 5. Интерактивный MVP экрана дашборда (`:feature:home`)
Перенос ключевых блоков из утвержденного Figma-макета с поддержкой темной и светлой тем:
- [ ] **Виджет общего баланса (Total Balance Card):**
    - Отображение суммарного остатка по всем счетам с динамическим расчётом доходов и расходов за текущий месяц;
    - Цветовая индикация положительного/отрицательного денежного потока.
- [ ] **Карусель счетов (Accounts Carousel):**
    - Горизонтальный скролл карточек счетов (наличные, дебетовая карта, накопительный счёт);
    - Отображение баланса и валюты каждого счёта из локальной базы Room.
- [ ] **Лента последних операций (Recent Transactions):**
    - Список последних 5–7 транзакций с иконками категорий, суммами и датами;
    - Состояние пустого экрана (Empty State), если база ещё не содержит операций.
- [ ] **Интерактив для демо-показа (Live Demo):**
    - Диалог быстрого добавления тестовой операции или кнопка добавления тестового расхода/дохода по клику на центральный «+»;
    - Автоматическое реактивное обновление баланса на карточке и появление новой строки в ленте через `StateFlow` без перезапуска экрана.
